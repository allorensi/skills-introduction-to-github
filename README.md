# 📚 Introducción a GitHub desde Cero

¡Bienvenido/a al curso completo de GitHub! Este repositorio te guiará paso a paso para aprender a usar GitHub desde el inicio, sin conocimientos previos necesarios.

## 🎯 ¿Qué aprenderás?

- **Conceptos básicos**: Qué es Git y GitHub

## 🚀 Empezando

### 1. ¿Qué es GitHub?

GitHub es una plataforma de desarrollo colaborativo que utiliza Git (sistema de control de versiones) para:
- **Guardar tu código** de forma segura en la nube
- **Colaborar** con otros desarrolladores
- **Mantener un historial** de todos los cambios en tu proyecto
- **Gestionar proyectos** con herramientas integradas

### 2. Configuración Inicial

#### Crear una cuenta en GitHub
1. Ve a [github.com](https://github.com)
2. Haz clic en "Sign up"
3. Completa el formulario de registro
4. Verifica tu email

#### Instalar Git en tu computadora
- **Windows**: Descarga desde [git-scm.com](https://git-scm.com)
- **macOS**: Instala con `brew install git` o descarga desde el sitio oficial
- **Linux**: `sudo apt install git` (Ubuntu/Debian) o `sudo yum install git` (CentOS/RHEL)

#### Configurar Git
```bash
git config --global user.name "Tu Nombre"
git config --global user.email "tu-email@ejemplo.com"
```
