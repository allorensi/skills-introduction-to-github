# Mi Portafolio Personal

Este es un ejemplo de proyecto que los estudiantes pueden usar para practicar Git y GitHub.

## Estructura del Proyecto

```
mi-portafolio/
├── README.md
├── index.html
├── styles/
│   └── main.css
├── scripts/
│   └── main.js
├── imagenes/
│   └── foto-perfil.jpg
└── proyectos/
    ├── proyecto1.md
    └── proyecto2.md
```

## Páginas del Sitio

- **Inicio**: Presentación personal
- **Sobre mí**: Información detallada
- **Proyectos**: Portfolio de trabajos
- **Contacto**: Información de contacto

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub Pages (para hosting)

## Cómo usar este ejemplo

1. **Clona este proyecto** o úsalo como referencia
2. **Personaliza el contenido** con tu información
3. **Practica Git** haciendo cambios y commits
4. **Experimenta con ramas** para nuevas características
5. **Publica en GitHub Pages** para tener tu sitio web

## Ejercicios Sugeridos

### Ejercicio 1: Personalización Básica
- Modifica `index.html` con tu información
- Actualiza el `README.md`
- Haz commit de los cambios

### Ejercicio 2: Trabajar con Ramas
- Crea rama `feature/nueva-seccion`
- Agrega una nueva sección al sitio
- Fusiona la rama con `main`

### Ejercicio 3: Colaboración
- Haz fork del repositorio de un compañero
- Sugiere mejoras via Pull Request
- Revisa Pull Requests de otros

## Ideas para Expandir
